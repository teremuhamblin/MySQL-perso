# Dashboard

Ce dossier contient l’interface du tableau de bord de l’application.  
Il regroupe la structure HTML, le style visuel et la logique JavaScript.

## Contenu
- **index.html** — Structure du tableau de bord  
- **style.css** — Mise en forme et thème visuel  
- **app.js** — Logique, interactions et chargement des données

## Objectif
Fournir une interface simple et fonctionnelle pour afficher les informations de l’application.

## Utilisation
Ouvrir `index.html` dans un navigateur.  
Adapter `app.js` selon les données ou modules utilisés.
