# MySQL-perso
- Ce dossier contient l’ensemble de la documentation technique et opérationnelle du projet **MySQL-perso**.  
- Il regroupe les informations nécessaires pour comprendre l’architecture, l’évolution du système et les procédures d’utilisation.

---

### Contenu du dossier
### 1. ROADMAP.md
- Plan d’évolution du projet de la version 1.0 à la version 3.0.  
Inclut :
```md
- Objectifs par version
- Modules ajoutés
- Documentation prévue
- CI/CD et structure du dépôt
```

### 2. CHANGELOG.md
- Historique complet des modifications du projet.  
Inclut :
```md
- Ajouts
- Corrections
- Réorganisations
- Versions publiées
```

### 3. Documentation technique
Ensemble des fichiers décrivant le fonctionnement interne du projet :
- Structure SQL (schémas, données, requêtes)
- Scripts avancés (maintenance, sécurité, monitoring)
- Notes MySQL
- Architecture globale du dépôt

---

### Objectif du dossier
Fournir une documentation claire, centralisée et professionnelle permettant :
- La compréhension rapide du projet
- La maintenance et l’évolution du système
- L’intégration dans un workflow CI/CD
- La consultation des versions et des changements

---

### Mise à jour
Toute modification majeure du projet doit être répercutée dans :
- `ROADMAP.md` pour la planification
- `CHANGELOG.md` pour l’historique
- La documentation technique pour les détails d’implémentation
