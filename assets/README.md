# Assets

Ce dossier regroupe les ressources statiques utilisées par l’application.

## Contenu
- **badges.md** — Fichier contenant les badges utilisés dans les différents README du projet.

## Objectif
Centraliser les éléments visuels et textuels afin de garder une structure claire et réutilisable.

## Utilisation
Importer ou copier les badges depuis `badges.md` dans les README concernés.
